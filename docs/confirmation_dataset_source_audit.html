Decision rules

Reject the source if independence or deterministic evidence fails.

Accept only if

  • the official file hash and lineage are recorded
  • the strict prior-period window has zero exact normalized record overlap with the current source
  • required fields remain sufficiently complete for deterministic gold calculations
  • cancellation and value rules can be documented without outcome-dependent exclusions
  • at least 48 disjoint evidence contexts satisfy the frozen split policy

Reject or redesign if

  • record overlap remains after the strict cutoff
  • missingness or duplicate ambiguity prevents deterministic evidence calculations
  • fewer than 48 eligible contexts can be formed without looking at generated answers
  • the proposed period split produces materially sparse or incomparable business scopes
